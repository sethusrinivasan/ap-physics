# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it privately:

1. Use [GitHub Private Vulnerability Reporting](https://github.com/sethusrinivasan/ap-physics/security/advisories/new) on this repository.
2. Please do **not** open a public issue or discuss potential vulnerabilities publicly until they have been addressed.

### Scope

- **In Scope**:
  - The static web player application and interactive scripts.
  - The `ap-physics-walkthrough` agent skill scripts and tooling.
  - GitHub Actions CI/CD workflows and deployment configurations.
- **Out of Scope**:
  - Educational content and official AP Physics C exam items/figures from the College Board.

### Response Time

We strive to acknowledge receipt of security reports within 48 hours and provide an assessment or fix within 7 business days.
